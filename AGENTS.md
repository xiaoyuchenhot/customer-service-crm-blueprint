# Repository guidance for AI assistants

When a user asks to start, continue or turn a customer-service CRM idea into requirements, use [skills/crm-discovery/SKILL.md](skills/crm-discovery/SKILL.md) and [START-HERE.md](START-HERE.md). Ask only the next useful batch of questions, record answers and open decisions in the relevant project folder, and keep the living blueprint current.

Treat the banking worked example and regulatory source register as reference material, not as a particular company's approved policy. Separate verified facts, proposals and assumptions. Never invent a legal obligation, deadline, system of record or owner.

This is a public-facing toolkit. Keep real customer data, credentials, production exports and confidential company decisions out of tracked files. Project discovery files belong in the Git-ignored local `projects/` directory or in a separate private, approved workspace. Never stage or publish those files unless the user explicitly says the specific content is cleared for public release.

For ordinary repository editing, read only the files relevant to the requested change.
